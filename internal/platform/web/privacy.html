workspace.

Permits Agent is a BC Software product. This notice describes the implemented pilot software. The operator must publish its contact information, retention period and service terms before inviting customers into a hosted deployment.

What is stored

Connected customers can save business intake, premises information and notes in a tenant-scoped database. Request accounting records contain a tenant identifier, operation path, timestamp and result status. The application does not log access keys or request bodies. Access keys are held in the browser tab’s memory, and the server credential file contains hashes.

When configured, usage records also identify the registered client and its intended human, agent or service use. Tool names, execution status, duration and owner-assistant token counts support restricted usage analytics. These metrics exclude prompts, tool arguments and results. Organization analytics require permission; product operators may be granted access to aggregate product-wide metrics. Automated telemetry retention and deletion are not yet implemented.

Keep sensitive documents out of the pilot

Do not enter Social Security numbers, tax identifiers, identity documents, payment details, agency passwords or other sensitive personal information. Secure document uploads, customer deletion controls and document retention policies have not been implemented. Use fictional data until the deployment’s storage, backups and privacy terms have been reviewed.

External services and actions

The website does not include advertising analytics or third-party scripts. Opening an official source link takes you to that provider’s site. An external agent client may process the information returned to it under that client’s terms. If the operator enables the owner assistant, asking it a question shares that question, the selected case intake, and at most its latest three notes with the configured model provider (and Cloudflare AI Gateway, if configured). Requests set model response storage off; this alone does not guarantee provider zero retention. Do not send sensitive applicant information. This product does not submit filings, send messages, collect customer payments or schedule appointments.

Access and deletion

Access is provisioned and revoked by the pilot operator. Ask your pilot contact for a data export, deletion or access-key rotation. A preparation brief is downloadable from the workspace; it is not a government filing. An operator must establish and test a backup and deletion process before accepting real applicant records.
