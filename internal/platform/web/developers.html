Permits Agent exposes the same preparation cases through its website, JSON API, and Streamable HTTP MCP endpoint. Access is currently provisioned by the operator for pilot customers.

Connect over MCP

Use your deployment’s /mcp endpoint with an Authorization: Bearer YOUR_ACCESS_KEY header. Choose a client that supports headers on Streamable HTTP. OAuth login and automatic connector-store installation are not implemented. 

{
  "mcpServers": {
    "permits-agent": {
      "url": "https://YOUR_DOMAIN/mcp",
      "headers": {"Authorization": "Bearer YOUR_ACCESS_KEY"}
    }
  }
}

Configuration syntax varies by agent client. Never place a real key in a public repository. Rotate keys through the operator. Product capability discovery is available at /.well-known/permits-agent.json.

One case, two ways to work

Tool Purpose Scope
source_catalog / source_read Find and retrieve curated official entry points with freshness and fingerprints research
plan_business Build a research checklist from California intake research
case_create Save intake with an idempotent request key cases:write
case_update_intake Update premises and activities at the current version, then rebuild the checklist cases:write
case_list / case_get Read paginated case summaries (limit 1–100, offset) or an individual case cases:read
case_add_note Record an owner answer or research evidence at a specified case version cases:write
case_export Download a draft preparation worksheet and correspondence cases:read
case_reminder Generate an owner-selected review reminder cases:read

Read-only ABC tools are also available with the research scope. Hosted queries use operator-refreshed caches, have a maximum page size of 200, and do not permit callers to refresh the shared data.

Call the JSON API

POST /api/call
Authorization: Bearer YOUR_ACCESS_KEY
Content-Type: application/json

{
  "name": "plan_business",
  "arguments": {
    "intake": {
      "business_name": "Example Café",
      "business_type": "Restaurant",
      "address": "",
      "city": "Los Angeles",
      "county": "Los Angeles",
      "jurisdiction": "unknown",
      "activities": ["food", "alcohol_retail", "employees"]
    }
  }
}

Results use the MCP tool result format: content, optional structuredContent, and isError. Check tool errors even when a protocol response succeeds. Preserve source freshness and uncertainty when explaining results to a customer.

What this version can do

  • Read official ABC license data and cached references with source provenance.
  • Prepare a California research checklist, including local jurisdiction, business registration, ABC and TTB investigation paths.
  • Keep separate customer cases, record user-supplied notes, and generate draft briefs and review reminders.
  • Attribute authenticated requests to the credential’s tenant and enforce request allowances.

What remains outside this version

This version does not automatically fill official PDFs, determine complete permit obligations, submit forms, sign, pay fees, send correspondence, book agency appointments, or execute autonomous filings. An external agent can use the tools to assist with preparation. The optional owner assistant uses a configured Responses model and bounded read-only ABC and official-source research tools; it requires explicit model credentials, an agent:read scope, and a tenant model-call allowance. It cannot write cases or take external actions. Its text cannot approve a filing or promote user-supplied notes to verified agency facts.

Local coverage is a research workflow, not a verified directory of every California city and county. CalGold itself warns that its information may be incomplete. CUP requirements depend on premises and use; the product does not infer that every alcohol business requires a CUP.

Usage and commercial availability

Each authenticated HTTP request, including errors and protocol calls, consumes one request allowance. Limits are shared across a tenant’s keys: 60 requests per rolling minute and the configured monthly quota. Usage events are operational accounting, not invoices. Customer billing, checkout, plan prices, and paid service terms are not active.
